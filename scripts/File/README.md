# scripts　＞　File


## 依頼チャット

雑用を頼んでいいかだぜ（＾～＾）？  
作ってほしい PowerShell スクリプトが２つあるんだぜ（＾▽＾）  
（１） 📄 `FileList.ps1`  
このスクリプトを実行したら、このスクリプトが置いてあるディレクトリーにある `.png` ファイルを一覧し、  
作成年月日の月別にグループ化してくれだぜ（＾▽＾）  
それを、 Windows の改行 CRLF かつ、UTF-8（BOM無し）エンコードで、 CSV 形式で出力してくれだぜ（＾▽＾）  
フォーマットは以下の通りだぜ（＾▽＾）  

| 生成年月 | ファイル名  |
|----------|-------------|
| 2026-09  | example.png |

（２） 📄 `FileTransfer.ps1`
このスクリプトを実行したら、このスクリプトが置いてあるディレクトリーに  
生成年月 `YYYY-MM` の名前をもったフォルダーを作ってくれだぜ（＾▽＾）  
既存ならそのままでいいぜ（＾▽＾）  
そして、 `FileList.csv` に書かれているファイルだけを、年月フォルダーへ移動してほしいんだぜ（＾～＾）  
その意図を分かりやすくするために、  
まず、`FileList.csv` ファイル名の入力を促すようなプロンプトをだしてくれだぜ（＾▽＾）  
デフォルトは `FileList.csv` で（＾▽＾）  
移動先に既存のファイルは、移動しないでくれだぜ（＾▽＾）  
作ったらとりあえずリポジトリーの scripts フォルダーに File フォルダーを作って、その下に置いておいてくれだぜ（＾～＾）  
できれば、スクリプトの中にはコメントを書いておいてくれだぜ（＾▽＾）
